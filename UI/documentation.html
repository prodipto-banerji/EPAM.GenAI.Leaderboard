EPAM GenAI Leaderboard — Integration & API Documentation

Everything your game application needs to submit scores and integrate with the leaderboard system

🎮 Game Application Integration Guide

This section explains how your game application should integrate with the Leaderboard API to submit player scores.

Quick Summary

  1. Poll for active slot: Keep calling GET /api/slots/active/:location every 5–10 seconds until a slot is active
  2. Optionally: Check if player email has already played in this slot
  3. Player plays the game
  4. After game ends: Submit the score via POST /api/player

Base URL: https://epam-genai-dashboard.azurewebsites.net

⏱️ Grace Period

Scores are accepted for up to 5 minutes after a slot is closed. If a player is mid-game when the admin closes the slot, their score will still be accepted. No special handling needed from the game app — just submit normally.

Step 1: Poll to check if a game slot is active

The game app should poll this endpoint to know when the admin starts a slot. Poll every 5–10 seconds until active === true, then allow the player to start.

GET /api/slots/active/{location}

// Example: GET /api/slots/active/Hyderabad

// Response when slot is active:
{
  "status": "success",
  "active": true,
  "slot": {
    "id": 3,
    "name": "Round 1",
    "status": "active",
    "location": "Hyderabad",
    "level": "simple",
    "start_time": "2026-06-16 10:00:00"
  }
}

// Response when NO slot is active:
{
  "status": "success",
  "active": false,
  "slot": null
}

Polling Example (JavaScript)

// Poll every 5 seconds until a slot becomes active
function waitForActiveSlot(location, onSlotActive) {
  const interval = setInterval(async () => {
    try {
      const res = await fetch(`/api/slots/active/${location}`);
      const data = await res.json();

      if (data.active) {
        clearInterval(interval);
        onSlotActive(data.slot); // Slot is active — start the game
      }
    } catch (err) {
      console.error('Polling error:', err);
    }
  }, 5000); // Poll every 5 seconds

  return interval; // Return so you can clearInterval() if user navigates away
}

// Usage
waitForActiveSlot('Hyderabad', (slot) => {
  console.log('Game started! Slot:', slot.name, 'Level:', slot.level);
  startGame(slot.level); // Your game logic
});

Game app logic: While active === false, show a waiting screen like "No game session running. Please wait for the admin to start a session." Once active === true, allow the player to begin.

Prevents duplicate plays within the same slot. Call this before starting the quiz.

Game app logic: If hasPlayed === true, show "You have already played in this session. Your score: X"

Step 3: Submit player score

After the player finishes the game, submit their score. This is the most important API call.

POST /api/player
Content-Type: application/json

{
  "name": "John Doe",
  "email": "john.doe@epam.com",
  "score": 8,
  "timetaken": 45000,
  "displaytime": "00:45",
  "location": "Hyderabad"
}

Field Reference

Field Type Required Description
namestring✅ YesPlayer's full name
emailstring✅ YesPlayer's email (used as unique identifier per slot)
scorenumber✅ YesNumber of correct answers (e.g., 8 out of 10)
timetakennumber✅ YesTime taken in milliseconds (e.g., 45000 = 45 seconds)
displaytimestring✅ YesHuman-readable time string (e.g., "00:45", "01:30", "12:05")
locationstring✅ YesMust be one of: Hyderabad, Pune, Chennai, Gurgaon, Bangalore, Coimbatore

Response

// Success - new player added:
{ "status": "success", "message": "Player added", "updated": true }

// Success - score updated (better than previous):
{ "status": "success", "message": "Score updated", "updated": true }

// Success - existing score is better (no update):
{ "status": "success", "message": "Existing score is better", "updated": false }

// Error - no active slot:
{ "status": "error", "message": "Failed to add player", "error": "No active slot available for this location" }

⚠️ Important Notes for Game App

  • Ranking logic: Players are ranked by highest score first, then by lowest time taken (faster = higher rank for equal scores).
  • Duplicate submissions: If the same email submits again in the same slot, only the better score is kept.
  • Slot assignment is automatic: You don't need to pass a slot_id. The API automatically assigns the score to the active slot for that location.
  • 5-minute grace period: Scores are accepted up to 5 minutes after a slot closes. No retry logic needed.
  • No WebSocket needed: Game apps should only use HTTP POST. WebSockets are for the dashboard display only.

Code Examples

JavaScript (fetch)

// Submit score after game ends
async function submitScore(playerName, playerEmail, score, timeTakenMs, location) {
  // Format display time from milliseconds
  const totalSeconds = Math.floor(timeTakenMs / 1000);
  const minutes = String(Math.floor(totalSeconds / 60)).padStart(2, '0');
  const seconds = String(totalSeconds % 60).padStart(2, '0');
  const displaytime = `${minutes}:${seconds}`;

  const response = await fetch('https://epam-genai-dashboard.azurewebsites.net/api/player', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      name: playerName,
      email: playerEmail,
      score: score,
      timetaken: timeTakenMs,
      displaytime: displaytime,
      location: location
    })
  });

  const result = await response.json();
  if (result.status === 'success') {
    console.log('Score submitted:', result.message);
  } else {
    console.error('Failed:', result.error);
  }
}

// Example usage
submitScore('John Doe', 'john.doe@epam.com', 8, 45000, 'Hyderabad');

Python (requests)

import requests

def submit_score(name, email, score, time_taken_ms, location):
    total_seconds = time_taken_ms // 1000
    displaytime = f"{total_seconds // 60:02d}:{total_seconds % 60:02d}"

    response = requests.post(
        "https://epam-genai-dashboard.azurewebsites.net/api/player",
        json={
            "name": name,
            "email": email,
            "score": score,
            "timetaken": time_taken_ms,
            "displaytime": displaytime,
            "location": location
        }
    )
    return response.json()

# Example
result = submit_score("John Doe", "john.doe@epam.com", 8, 45000, "Hyderabad")
print(result)

The name of the new slot to start

location optional

EPAM GenAI Leaderboard API Documentation

API documentation for interacting with the EPAM GenAI Leaderboard system

API Endpoints

POST /api/auth/login
Authenticate an admin user. Returns the associated location on success.

Request Body

email required

Admin email (e.g. hyderabad@admin.com)

password required

Admin password

Response

{
  "status": "success",
  "location": "Hyderabad"
}
POST /api/player
Add or update a player in the leaderboard

Request Body

location required

The location of the player

Response

{
  "status": "success",
  "message": "Player added/updated successfully",
  "updated": boolean
}
GET /api/slots
Get all available game slots

Response

[{
  "id": "string",
  "name": "string",
  "active": boolean,
  "created_at": "timestamp"
}]
POST /api/slots/start
Start a new game slot for a specific location. Each location can have one active slot at a time.

Request Body

slotName required

The name of the new slot to start

location optional

The location for this slot (e.g. Hyderabad, Pune, Chennai, Gurgaon, Bangalore, Coimbatore)

level optional

Game difficulty level: "simple" or "advanced". Defaults to "simple".

Response

{
  "status": "success",
  "data": {
    "id": number,
    "name": "string",
    "status": "active",
    "location": "string",
    "level": "simple" | "advanced",
    "start_time": "timestamp"
  }
}
POST /api/slots/:slotId/stop
Stop an active game slot

URL Parameters

slotId required

The ID of the slot to stop

Response

{
  "status": "success",
  "data": {
    "id": "string",
    "name": "string",
    "active": false,
    "created_at": "timestamp"
  }
}
GET /api/slots/:slotId/players
Get players for a specific slot

URL Parameters

slotId required

The ID of the slot

Query Parameters

location optional

Filter players by location

Response

[{
  "id": "string",
  "name": "string",
  "score": number,
  "location": "string"
}]
GET /api/rankings/:location
Get rankings for a specific location

URL Parameters

location required

The location to get rankings for

Response

[{
  "id": "string",
  "name": "string",
  "score": number,
  "location": "string"
}]
POST /api/check-email
Check if an email has already played in the currently active slot

Request Body

email required

The email address to check

location optional

The location to check the active slot for

Response

{
  "status": "success",
  "hasPlayed": boolean,
  "message": "string",
  "activeSlot": {
    "id": "number",
    "name": "string",
    "status": "string",
    "start_time": "timestamp"
  },
  "playerData": {
    "id": "number",
    "name": "string",
    "email": "string",
    "score": "number",
    "timetaken": "number",
    "displaytime": "string"
  } || null
}
GET /api/slots/location/:location
Get all slots for a specific location

URL Parameters

location required

The location name (Hyderabad, Pune, Chennai, Gurgaon, Bangalore, Coimbatore)

Response

[{
  "id": number,
  "name": "string",
  "status": "active" | "completed",
  "location": "string",
  "level": "simple" | "advanced",
  "start_time": "timestamp",
  "end_time": "timestamp" | null,
  "duration": "MM:SS" | "HH:MM:SS"
}]
GET /api/slots/active/:location
Get the currently active slot for a specific location

URL Parameters

location required

The location name (Hyderabad, Pune, Chennai, Gurgaon, Bangalore, Coimbatore)

Response (slot running)

{
  "status": "success",
  "active": true,
  "slot": {
    "id": number,
    "name": "string",
    "status": "active",
    "location": "string",
    "level": "simple" | "advanced",
    "start_time": "timestamp",
    "end_time": null
  }
}

Response (no active slot)

{
  "status": "success",
  "active": false,
  "slot": null
}
